Open source licenses

Updated on Nov 21, 2026

Zappy TV uses open source components. We thank their authors. This page lists these components, their licenses and where to get the source code.

Zappy TV for Windows

libVLC (VLC media player 3.0.21)

The Windows installer includes the libVLC library and its modules, by VideoLAN, distributed under the GNU Lesser General Public License, version 2.1 or later (LGPL). The modules are separate DLL files in the app's installation folder and can be replaced with another compatible version.

  • VLC 3.0.21 source code: download.videolan.org/pub/videolan/vlc/3.0.21
  • Project website: videolan.org

FFmpeg (libavcodec and related libraries)

Included in the libVLC above, built in LGPL mode (LGPL version 2.1 or later). The source code used is part of the VLC 3.0.21 source packages and is available at ffmpeg.org.

If you'd like a copy of the source code of these components in the exact version we distribute, write to fabiofish@gmail.com. This offer is valid for at least 3 years from the last distribution of this version.
